### How to use
1. Go to the [website](https://jascii.jassi.dev)
2. Simply upload the picture. (Note: Only `.jpg`, `.jpeg`, and `.png`formats are allowed)
3. Ta-da! There you have it.
4. Use the reset button to convert another image to ASCII.
